# 管理页（`durweg ui`）

在浏览器里做 Durweg 周边的事，不用敲命令：看有哪些工作流可以装、加入和移除、保持更新、管理目录、看这台电脑的情况。运行工作流仍然在终端里和 agent 一起做；页面给你要说的那句话。

1. 打开终端（Windows：PowerShell，再输入 `wsl`）。
2. 运行 `durweg ui`。它打印一个链接，并用浏览器打开。
   - 浏览器没有打开（例如通过 SSH）：把链接复制到这台电脑的浏览器里。
3. 用三个标签页：

| 标签页 | 在这里做什么 |
| :--- | :--- |
| 浏览（Browse） | • 已打开的目录里的工作流<br>• **加入** 安装一个；方法库里已经有同名工作流的，会标出来，不给加入按钮 |
| 已装（Installed） | • 你的方法库<br>• **运行** 显示要对 agent 说的话；**更新**；**移除**（文件夹留在这台电脑上） |
| 这台电脑（This computer） | • Claude Code、Codex、Antigravity：装没装，有没有 Durweg<br>• GitHub 登录（要登录：在终端里运行 `gh auth login --web`）<br>• 目录：加入、移除、关掉和打开公开目录、建私人目录（先看到将要做什么） |

右上角 **全部更新** 和 `durweg update` 做的一样。改动一次只做一个，列在 **改动** 下，写明每个工作流的结果。

## 🔒 要知道的

- 页面只能从这台电脑访问（`127.0.0.1`），只有启动时打印的链接能做修改。刷新或在新标签页打开后，页面照样能看，但按钮变灰：请重新打开打印的链接。
- 在终端里按 `Ctrl-C` 停止；30 分钟没人用也会自己停。
- 打开浏览器时，链接（带这次启动的钥匙）会交给打开浏览器的程序。和别人共用的电脑上，请用 `durweg ui --no-browser`，自己粘贴链接。
- **全部更新** 更新了 Durweg 本身之后，请关掉页面，再运行一次 `durweg ui`。
